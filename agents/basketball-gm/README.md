# Basketball GM AI Agent — Steam Deck experiments

**Status:** Synthetic research prototypes (V1–V5.1). No script in this folder currently controls the real Basketball GM simulation engine. The `--league` mode in V1 can read a Basketball GM export for advisory purposes only.

This module belongs to the BBGM Simulation Lab project. It is designed to remain **isolated** from the existing source tree, Golden Master league, and official sim results.

## Prerequisites
- Python 3 (standard library; no pip packages required)
- Optional LLM: Alpaca-managed Ollama, reachable at `http://127.0.0.1:11435`, with `qwen3:8b` installed
- A Steam Deck OLED with Ollama Vulkan acceleration confirmed for LLM tests
- Run commands from the directory containing these files, or invoke using their full paths. Some evaluators import earlier scripts from this directory.

### Launch the locally hosted model (only for LLM tests)
```bash
flatpak run --env=OLLAMA_IGPU_ENABLE=1 --env=OLLAMA_VULKAN=1 com.jeffser.Alpaca
```
Then check from a second terminal:
```bash
curl -sS --max-time 10 http://127.0.0.1:11435/api/version
```
Keep Ollama bound to loopback unless separately configuring secure, authorized remote access.

## Start here on Steam Deck
Offline Python policy training:
```bash
python3 bbgm_deck_learning_v2.py
```
Offline multi-season training:
```bash

```


## Data and reproducibility
- Default generated data is stored at `~/BBGMDeckAgentLab/`, outside this repository.
- Local `policy_v2.json` is generated by V2, and later V3/V4 scripts read it. If starting on a new machine, run V2 first.
- Keep seeds and test settings in experiment reports for repeatability. Avoid testing repeatedly on the same held-out set and reporting it as unseen.
- Do not commit private BBGM league exports, model weights, tokens, personal log data or unnecessary generated artifacts.
- Policy scores are estimates from **invented toy mechanics**. This is not evidence the policy will win in the actual BBGM engine.
- Model weights for Qwen3 are not trained or modified here. V2 and V5 fit separate small Python policies.

## Integrating with the main BBGM Simulation Lab
Recommended subproject folder: `agents/basketball-gm/`.
Keep it on a separate Git branch while validating. Don't modify the lab's Golden Master, `results/`, or source copies of ZenGM. When the actual BBGM control adapter is implemented, add it as a new module and make it explicit whether it reads or mutates league saves.
