# Basketball GM Simulation Lab

A Linux-based simulation lab for testing how individual player attributes affect team performance in Basketball GM.

## Project Goals

- Build a repeatable Basketball GM simulation environment.
- Run controlled experiments using standardized teams and players.
- Compare the effects of individual player attributes.
- Run simulations across multiple computers.
- Collect and analyze simulation results.
- Explore a future promotion and relegation league system.

## Lab Systems

### BBGMBox
- Platform: VirtualBox
- Operating System: Ubuntu Linux
- Role: Primary development and simulation node

### Steam Deck
- Platform: SteamOS
- Role: Secondary simulation node
